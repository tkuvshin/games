# Игровой портал «Огонёк»

Браузерные игры по пожарной безопасности.

## Структура проекта

- `index.html` — главная страница портала (каталог игр).
- `style.css` — общие стили портала.
- `games/manifest.json` — манифест каталога игр.
- `games/extinguishers/` — первая игра (будет добавлена на следующем этапе).

## Как добавить новую игру

1. Создайте папку игры в `games/`.
2. Добавьте запись в `games/manifest.json`:
   ```json
   {
     "id": "новая-игра",
     "title": "Название",
     "description": "Описание",
     "icon": "🔥",
     "type": "pro",
     "path": "games/новая-игра/index.html"
   }
